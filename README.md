# Canon EOS R6 Mark III · Alaska Field Guide

An offline-capable, swipe-through quick start guide for the Canon EOS R6 Mark III, tailored for shooting Alaska wildlife, landscapes, and family portraits with a 50mm, 100mm, and RF 200–800mm.

**Live:** https://wfilleman.github.io/canon-r6iii-quickstart/

## Use it on the boat

1. Open the live URL above in Safari on your iPhone (or any browser).
2. Tap **Share → Add to Home Screen**.
3. From now on it works fully offline — the service worker caches the entire app on first load.

## What's inside

A 14-slide deck covering:

- Quick first-time setup checklist
- Mode dial refresher (focused on **Av**)
- What's automatic vs. manual in Av mode
- Autofocus deep-dive (Servo, AF area modes, subject detection, **back-button focus setup**)
- Daily-driver baseline settings
- Wildlife settings for the RF 200–800 (bears, eagles, BIF, whales)
- Landscape settings for the 50mm (glaciers, mountains, fjords)
- Family portrait settings (50mm & 100mm)
- Low light / golden hour / midnight sun
- Video — highest-quality modes (7K Open Gate RAW, 4K FINE)
- Drive modes & **pre-continuous shooting**
- Practical Alaska tips (cold, condensation, cards, backup)
- A one-glance cheat sheet

## Navigation

- Swipe left/right on touch
- Arrow keys on desktop
- Tap the screen edges
- Click any dot at the bottom to jump
- Each slide is hash-addressable (`#wildlife`, `#cheat`, …)
